Clarity Notes — design principles

DISTINCTIVE THREAD: "a quiet room". Everything is calm, unhurried and low-contrast-noise. Warm paper ground, one soft teal signal, generously rounded surfaces, oversized touch targets, and never more than one thing asking for attention at a time. The opposite of a productivity tool: no dense chrome, no badges, no counters, no urgency colors. Emptiness is the design, not a gap to fill.

AUDIENCE: adults with mild cognitive impairment or word-finding difficulty. Legibility and predictability outrank density and cleverness. Same control in the same place on every screen. Plain, reassuring copy — never clinical, never playful. The app is an assistive tool, NOT a medical device; the disclaimer stays.

MODES: both light and dark, equal care. Light is warm off-white paper; dark is warm near-black, never blue-black.

PACING: generous. Large default type (17-18px body, 20px+ in the note editor), 1.6+ line height, wide line spacing, big margins, few elements per screen. Tap targets 48px minimum, 56px for primary actions.

COLOR: warm off-white / warm ink neutrals tinted toward the teal family. ONE dominant accent — soft teal — used for primary actions, active states and focus. Destructive terracotta appears only in confirmations. Suggestion bubbles carry three quiet category tints (deeper violet, continue amber-clay, forward green) used as text + hairline border only, never as filled saturated chips.

TYPE: Fraunces (soft optical serif) for the wordmark and screen titles only — warmth and a sense of a personal notebook. Nunito Sans (rounded, open apertures, high x-height) for everything the user reads or acts on: note text, buttons, labels, suggestions. Never mix a third face. Weights stay 400/600/700; no light weights anywhere.

MATERIAL: 14px radius on cards, inputs and buttons; full-round on suggestion bubbles and avatars. Shadows are soft, wide and low-opacity — surfaces sit on the paper rather than float above it. Borders are hairline warm greys, never black.

MOTION: slow and few. Fades and gentle slides only, 200-320ms. Nothing bounces, nothing pulses, nothing auto-dismisses fast. Suggestions appear by fading in, never by sliding the text the user is writing.

TEXT SCALE: the whole UI is authored in rem so an "extra-large text" preference can scale it globally by changing the root font size. Never hardcode px font sizes.
